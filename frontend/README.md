# Мой Склад — Frontend

React-интерфейс для системы управления складом. Подключается к FastAPI только через модули в `src/api`.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Укажите адрес Backend: `VITE_API_URL=http://localhost:8000`.
3. Выполните `npm run dev`.

## Что готово

- регистрация, вход и хранение JWT;
- защищённые маршруты и выход из аккаунта;
- Dashboard с карточками, графиком, топом и низкими остатками;
- каталог товаров с поиском и удалением;
- формы товара, приёма партий и продажи;
- адаптивное меню;
- отдельный API-слой для auth, товаров, категорий, партий, продаж, статистики, истории и admin.

До запуска Backend Dashboard показывает демонстрационные данные. Остальные операции выводят понятную ошибку сети и готовы к фактическим endpoint-ам FastAPI.
